# Accessing the Lab

Getting DNS Servers in Our Kali Machine
>``` shell
>kali@kali:~$ cat /etc/resolv.conf
>
># ========== Expected Result ==========
># Generated by NetworkManager
>nameserver 1.1.1.1
># =====================================
>```

Modifying /etc/resolv.conf to Add a New Nameserver
>``` shell
>kali@kali:~$ sudo nano /etc/resolv.conf
>
># ========== Expected Result ==========
>[sudo] password for kali:
># =====================================
>
>kali@kali:~$ cat /etc/resolv.conf
>
># ========== Expected Result ==========
># Generated by NetworkManager
>nameserver 44.205.254.229
>nameserver 1.1.1.1
># =====================================
>```

Testing DNS Configurations in Kali Using host Tool
>``` shell
>kali@kali:~$ host www.offseclab.io 44.205.254.229
>
># ========== Expected Result ==========
>www.offseclab.io has address 52.70.117.69
># =====================================
>
>kali@kali:~$ host www.offseclab.io 
>
># ========== Expected Result ==========
>www.offseclab.io has address 52.70.117.69
># =====================================
>```

Resetting the DNS Settings
>``` shell
>kali@kali:~$ sudo systemctl restart NetworkManager
>
># ========== Expected Result ==========

>
>kali@kali:~$ cat /etc/resolv.conf

>```
